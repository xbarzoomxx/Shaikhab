# بوابة أسرة الشيخاب

موقع لتوثيق بيانات أفراد أسرة الشيخاب، مع صفحة بحث عامة ولوحة تحكم مبسّطة، وقاعدة البيانات هي **ملف Google Sheet نفسه** — بدون أي API أو حساب خدمة (Service Account).

## طريقة العمل

الموقع لا يتصل بـ Google عبر أي مفتاح API. بدلاً من ذلك:

1. تشارك ملف Google Sheet كـ **"أي شخص لديه الرابط - عرض (Viewer)"**.
2. الموقع يقرأ بيانات الملف مباشرة (كملف CSV عام) في كل مرة يفتح فيها أحد الصفحة — بدون أي إعداد اتصال معقّد.
3. أي تعديل أو إضافة تتم **مباشرة داخل ملف Google Sheet نفسه** من قبل من يملك صلاحية تحرير الملف (أنت أو من تختاره) — والتغييرات تظهر في الموقع فوراً عند تحديث الصفحة.

هذا يعني: لا حاجة لإنشاء مشروع Google Cloud ولا حساب خدمة ولا مفاتيح API — فقط رابط الملف.

---

## الخطوة 1: مشاركة ملف Google Sheet

1. افتح الملف الذي سترسل لي رابطه.
2. اضغط **مشاركة (Share)** أعلى يمين الصفحة.
3. تحت "الوصول العام (General access)" اختر **"أي شخص لديه الرابط (Anyone with the link)"** وتأكد أن الصلاحية **"عارض (Viewer)"** (وليس محرر) — هذا يتيح لأي زائر للموقع رؤية البيانات، لكن لا يسمح له بتعديلها.
4. انسخ الرابط، فهو ما أحتاجه لربط الموقع بالملف (المعرّف هو الجزء بين `/d/` و `/edit` في الرابط).

من سيتولى **تعديل** البيانات (إضافة/تحديث الأفراد) يحتاج هو تحديداً لصلاحية تحرير منفصلة على نفس الملف (تُضاف له بالاسم أو بريده الإلكتروني من نفس نافذة المشاركة) — بينما بقية الأسرة تبقى "عارض" فقط عبر الرابط العام.

## الخطوة 2: أسماء التبويبات الثلاثة

الموقع الآن يعرض **الأقسام الثلاثة** كتبويبات منفصلة في نفس الصفحة (الدليل العائلي، الصندوق التكافولي، أعضاء الجمعية)، ويقرأ كل قسم من تبويب مختلف داخل نفس ملف Google Sheet.

- إن كانت تبويبات ملفك تحمل الأسماء نفسها المستخدمة في نموذج التسجيل الذي أرسلته لكم (`الأفراد`، `الصندوق التكافولي`، `أعضاء الجمعية`) — لا حاجة لأي إعداد إضافي، فهذه هي القيم الافتراضية.
- إن كانت أسماء التبويبات عندكم مختلفة، اضبطوا القيم التالية عند النشر على Vercel لتطابق الأسماء الفعلية حرفياً:

  | المتغير | التبويب الذي يقرأه |
  |---|---|
  | `GOOGLE_SHEET_TAB_MEMBERS` | الدليل العائلي العام |
  | `GOOGLE_SHEET_TAB_SUBSCRIPTIONS` | الصندوق التكافولي |
  | `GOOGLE_SHEET_TAB_OFFICIALS` | أعضاء الجمعية |

- عناوين الأعمدة (الصف الأول من كل تبويب) تظهر كما هي، بأي لغة أو تسمية — لا حاجة لتطابق أسماء حقول برمجية معيّنة.

## الخطوة 4: النشر على Vercel

1. سجّل دخول إلى [vercel.com](https://vercel.com) (يمكن الدخول مباشرة بحساب GitHub).
2. **Add New > Project**، واختر المستودع الذي رفعته.
3. Vercel يتعرف تلقائياً أنه مشروع Next.js — لا تغيير على إعدادات البناء.
4. قبل الضغط على Deploy، أضف متغيرات البيئة التالية من قسم **Environment Variables**:

   | المتغير | القيمة |
   |---|---|
   | `GOOGLE_SHEET_ID` | معرّف الملف أو الرابط كاملاً |
   | `GOOGLE_SHEET_TAB_MEMBERS` | اسم تبويب الدليل العائلي (افتراضياً: الأفراد) |
   | `GOOGLE_SHEET_TAB_SUBSCRIPTIONS` | اسم تبويب الصندوق التكافولي (افتراضياً: الصندوق التكافولي) |
   | `GOOGLE_SHEET_TAB_OFFICIALS` | اسم تبويب أعضاء الجمعية (افتراضياً: أعضاء الجمعية) |
   | `ADMIN_PASSWORD` | كلمة مرور من اختيارك لدخول لوحة العرض الخاصة بالمسؤول |
   | `SESSION_SECRET` | نص عشوائي طويل (مثلاً عبر `openssl rand -hex 32`) |

5. اضغط **Deploy**. خلال دقيقة يصبح الموقع جاهزاً على رابط مثل `shaikhab-portal.vercel.app`.

## الاستخدام اليومي

- **الصفحة العامة `/`**: 3 تبويبات أعلى الصفحة (الدليل العائلي، الصندوق التكافولي، أعضاء الجمعية)، كل واحد بحثه وفلترته المستقلة، مبنية تلقائياً حسب أعمدة كل تبويب في الملف.
- **لوحة المسؤول `/admin`** (محمية بكلمة مرور): نفس الأقسام الثلاثة في جدول كامل، بحث سريع، تصدير كل قسم كملف Excel منفصل، وأداة لتجهيز كشف مستورد من Excel/CSV بصيغة جاهزة للصق في أي تبويب.
- **إضافة/تعديل فرد**: من داخل لوحة المسؤول اضغط زر "فتح ملف Google Sheet للتعديل"، وعدّل الصف مباشرة في التبويب المناسب هناك.

## استكشاف الأخطاء

- **"لا يمكن الوصول إلى الملف"**: تأكد أن إعداد المشاركة هو "أي شخص لديه الرابط - عارض"، وأن `GOOGLE_SHEET_ID` صحيح.
- **"تعذّر العثور على التبويب"**: تأكد أن `GOOGLE_SHEET_TAB_NAME` مطابق تماماً لاسم التبويب داخل الملف (حساس لحالة الأحرف).
- **نسيان كلمة مرور المسؤول**: غيّر `ADMIN_PASSWORD` من إعدادات Vercel وأعد النشر (Redeploy).

## التطوير محلياً (اختياري)

```bash
npm install
cp .env.example .env.local   # ثم عدّل القيم داخل .env.local
npm run dev
```
الموقع سيعمل على `http://localhost:3000`.

**ملاحظة:** بيئة الاختبار التي بنيت فيها هذا المشروع لا تملك وصولاً لشبكة Google، لذا لم أتمكن من اختبار قراءة ملف حقيقي من هنا مباشرة — لكن الطريقة (قراءة رابط تصدير CSV العام لملف Google Sheet) طريقة قياسية ومجرّبة، وستعمل فوراً بمجرد تشغيل المشروع محلياً على جهازك أو نشره على Vercel (كلاهما يملك اتصالاً كاملاً بالإنترنت).
