# بوابة أسرة الشيخاب

موقع لتوثيق بيانات أفراد أسرة الشيخاب، مع صفحة بحث عامة ولوحة تحكم مبسّطة، وقاعدة البيانات هي **ملف Google Sheet نفسه** — بدون أي API أو حساب خدمة (Service Account)، وبدون أي إعداد متغيرات بيئة مطلوب في Vercel.

## نشر بدون أي إعدادات (Zero Config)

معرّف ملف Google Sheet مدمج مباشرة في الكود (`lib/config.js`) — وهذا آمن تماماً لأن الملف أصلاً مُشارَك كـ "أي شخص لديه الرابط - عرض"، أي أن معرّفه ليس سرّاً بالأساس. لذلك يكفي رفع المشروع إلى GitHub واستيراده في Vercel والضغط على Deploy مباشرة، دون إضافة أي Environment Variables.

⚠️ **كلمة مرور لوحة المسؤول الافتراضية هي:** `shaikhab2026`

بما أنها مكتوبة في الكود لتفادي أي إعداد، فإن أي شخص يملك حق الوصول لمستودع GitHub (repo) يمكنه رؤيتها. إن كان المستودع **خاصاً (Private)** فهذا ليس مصدر قلق. أما إن كان **عاماً (Public)**، أنصحك بأحد الخيارين:
- تغيير القيمة مباشرة في ملف `lib/config.js` (المتغير `DEFAULT_ADMIN_PASSWORD`) قبل الرفع، أو
- إضافة متغير بيئة `ADMIN_PASSWORD` في Vercel بقيمة من اختيارك — سيتم استخدامه تلقائياً بدل الافتراضي دون أي تعديل آخر على الكود.

نفس المبدأ ينطبق على `SESSION_SECRET` (مفتاح توقيع الجلسة) إن رغبت بتغييره لاحقاً.

## ✅ مُهيّأ مسبقاً لملفكم

تحققت من ملف Google Sheet الذي أرسلتموه وهو جاهز تماماً:
- المشاركة مضبوطة على "أي شخص لديه الرابط - عارض" — لا حاجة لأي تغيير.
- أسماء التبويبات الثلاثة (`الأفراد`، `الصندوق التكافولي`، `أعضاء الجمعية`) مطابقة تماماً لما هو مُعدّ في الكود.
- معرّف الملف مدمج مسبقاً في `lib/config.js`.

بقي فقط: رفع الكود ونشره.

## الخطوة 1: رفع الكود إلى GitHub

```bash
git init
git add .
git commit -m "بوابة أسرة الشيخاب"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

## الخطوة 2: النشر على Vercel

1. سجّل دخول إلى [vercel.com](https://vercel.com) (يمكن الدخول مباشرة بحساب GitHub).
2. **Add New > Project**، واختر المستودع الذي رفعته.
3. Vercel يتعرف تلقائياً أنه مشروع Next.js — لا تغيير على إعدادات البناء، ولا حاجة لإضافة أي Environment Variables.
4. اضغط **Deploy** مباشرة. خلال دقيقة يصبح الموقع جاهزاً على رابط مثل `shaikhab-portal.vercel.app`.

(إذا رغبت لاحقاً بتغيير كلمة مرور المسؤول أو ربط ملف آخر دون تعديل الكود، يمكنك حينها إضافة `ADMIN_PASSWORD` أو `GOOGLE_SHEET_ID` من Environment Variables في أي وقت — راجع `.env.example`.)

## هيكلة الموقع

الموقع الآن ثلاث قوائم رئيسية في الشريط العلوي (مع قائمة منسدلة على الجوال):

- **الدليل العائلي `/`** — دليل بحث في كل أفراد الأسرة.
- **البرنامج التكافلي `/takaful`** — صفحة شاملة تضم: اللائحة الرسمية كاملة، إحصائيات سريعة (عدد المشتركين، الإجمالي المحصّل، عدد المتأخرين...)، سجل الاشتراكات القابل للبحث، وقائمة اللجنة المسؤولة عن الصندوق.
- **أعضاء الجمعية `/society`** — دليل بحث في الأعضاء الرسميين للجمعية.

كل قسم يُقرأ من تبويب مختلف في نفس ملف Google Sheet كما سبق شرحه.

## الاستخدام اليومي

- **الصفحة العامة `/`**: 3 تبويبات أعلى الصفحة (الدليل العائلي، الصندوق التكافولي، أعضاء الجمعية)، كل واحد بحثه وفلترته المستقلة، مبنية تلقائياً حسب أعمدة كل تبويب في الملف.
- **لوحة المسؤول `/admin`** (محمية بكلمة مرور): نفس الأقسام الثلاثة في جدول كامل، بحث سريع، تصدير كل قسم كملف Excel منفصل، وأداة لتجهيز كشف مستورد من Excel/CSV بصيغة جاهزة للصق في أي تبويب.
- **إضافة/تعديل فرد**: من داخل لوحة المسؤول اضغط زر "فتح ملف Google Sheet للتعديل"، وعدّل الصف مباشرة في التبويب المناسب هناك.

## استكشاف الأخطاء

- **"لا يمكن الوصول إلى الملف"**: تأكد أن إعداد المشاركة على ملف Google Sheet ما زال "أي شخص لديه الرابط - عارض" (قد يتغير إذا عدّل أحدهم إعدادات المشاركة لاحقاً).
- **تسجيل الدخول للوحة المسؤول**: كلمة المرور الافتراضية `shaikhab2026` ما لم تُغيّر (راجع تنبيه الأمان في أعلى الملف).

## التطوير محلياً (اختياري)

```bash
npm install
cp .env.example .env.local   # ثم عدّل القيم داخل .env.local
npm run dev
```
الموقع سيعمل على `http://localhost:3000`.

**ملاحظة:** بيئة الاختبار التي بنيت فيها هذا المشروع لا تملك وصولاً لشبكة Google، لذا لم أتمكن من اختبار قراءة ملف حقيقي من هنا مباشرة — لكن الطريقة (قراءة رابط تصدير CSV العام لملف Google Sheet) طريقة قياسية ومجرّبة، وستعمل فوراً بمجرد تشغيل المشروع محلياً على جهازك أو نشره على Vercel (كلاهما يملك اتصالاً كاملاً بالإنترنت).
